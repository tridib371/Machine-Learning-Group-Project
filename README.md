# 🧠 Brain Tumor Detection System — Machine Learning Group Project (Python)

Welcome to **Brain Tumor Detection System**, a **machine learning project** developed in **Python** using **Google Colab**.  
This group project demonstrates how to **detect brain tumors from MRI scans** using **image processing and deep learning techniques**.

---

## 📘 Overview

The **Brain Tumor Detection System** is a Python-based ML project that:

- Uses **MRI brain scan images** to detect the presence of tumors  
- Implements **image preprocessing** techniques  
- Utilizes **machine learning / deep learning algorithms** for classification  
- Provides a **prediction system** for brain tumor detection  

This project is suitable for students and researchers who want to **learn practical AI applications in medical imaging**.

---

## 🧩 Key Features

- 🧠 Brain tumor detection from MRI images  
- 📊 Image preprocessing using **OpenCV** and **NumPy**  
- 🧮 Model training and testing using **TensorFlow / Keras**  
- 🔍 Evaluation metrics: Accuracy, Precision, Recall, F1-Score  
- 🖥️ Fully executable in **Google Colab**
